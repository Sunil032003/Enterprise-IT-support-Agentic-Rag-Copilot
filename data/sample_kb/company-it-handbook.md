## 1. Purpose

This document defines the company's standard IT support policies and procedures for password resets, software installation, VPN connections, and lost or stolen company laptops.

The purpose of these policies is to protect company systems, data, devices, and users while providing clear procedures for resolving common IT issues.

# 2. Password Reset Policy

## 2.1 Purpose

This policy defines the procedure employees must follow when they forget their company password, become locked out of their account, or suspect that their password has been compromised.

## 2.2 Scope

This policy applies to all employees, contractors, interns, and authorized users who access company systems, applications, networks, or services.

## 2.3 Password Requirements

Company passwords should:

- Be at least 12 characters long.
- Use a combination of uppercase letters, lowercase letters, numbers, and special characters where supported.
- Not contain the employee's name, username, employee ID, or easily predictable information.
- Not be reused across company and personal accounts.
- Not be shared with colleagues, managers, or IT personnel.
- Not be stored in plain-text documents or spreadsheets.

## 2.4 When a Password Reset Is Required

Users should request a password reset when:

- They forget their password.
- Their account becomes locked.
- They suspect their password has been compromised.
- They receive suspicious login notifications.
- IT Security instructs them to change their password.

## 2.5 Password Reset Procedure

1. Open the company's identity or account management portal.
2. Select **Forgot Password** or **Reset Password**.
3. Enter the registered company email address or username.
4. Complete the required identity verification process.
5. Create a new password that meets company requirements.
6. Sign in again using the new password.

## 2.6 If Self-Service Password Reset Is Not Available

If the employee cannot reset the password through the self-service portal, they must contact the IT Help Desk.

IT support personnel may verify the user's identity before resetting the account.

Employees must not ask another employee to reset a password on their behalf.

## 2.7 Suspected Password Compromise

If a user believes that their password has been compromised, they must:

1. Change the password immediately.
2. Contact the IT Help Desk or Security Team.
3. Report suspicious login notifications.
4. Follow any additional security instructions provided by IT Security.

IT support personnel will never ask users to provide their current password.

Users must never send passwords through email, chat, or support tickets.

# 3. Software Installation Process and Policy

## 3.1 Purpose

This policy defines the process for requesting, approving, installing, and maintaining software on company-owned computers and devices.

The objective is to ensure that software is secure, properly licensed, compatible, and approved by the company.

## 3.2 Scope

This policy applies to all employees, contractors, interns, and authorized users who use company-owned computers, laptops, virtual machines, or other managed devices.

## 3.3 Approved Software

Only software approved by the IT Department may be installed on company-owned devices.

Examples include:

- Microsoft Office
- Approved web browsers
- Company-approved development tools
- Approved communication applications
- Company-approved security software
- Applications listed in the company software catalog

## 3.4 Prohibited Software

Employees must not install:

- Pirated software.
- Cracked applications.
- Unauthorized VPN software.
- Unapproved remote-access software.
- Software obtained from suspicious or untrusted websites.
- Applications that bypass company security controls.
- Software that has not been approved by IT.

## 3.5 Software Installation Request

Employees who require new software must submit a software installation request through the IT service portal.

The request should include:

- Employee name
- Department
- Device name or asset ID
- Software name
- Software version, if known
- Business purpose
- Required installation date
- Manager approval, when required

## 3.6 Approval Process

The IT Department reviews the software request.

The review may include:

- Security assessment
- License verification
- Compatibility testing
- Privacy assessment
- Business justification
- Cost evaluation

If the software is approved, IT schedules the installation.

## 3.7 Installation Process

Authorized IT personnel will:

1. Verify the approved request.
2. Confirm the software source.
3. Verify the software version.
4. Scan the installation package for security threats.
5. Install the software.
6. Apply required security configurations.
7. Verify that the application works correctly.
8. Record the installation in the asset management system.

## 3.8 Employee Responsibilities

Employees must not bypass administrative restrictions to install software.

Employees must report unexpected software installations or suspicious applications to IT Security.

## 3.9 Software Updates

Approved software must be kept up to date.

Critical security updates should be installed as soon as reasonably possible.

## 3.10 Exceptions

Any exception to this policy requires approval from the IT Department and, when applicable, the Information Security Team.

# 4. VPN Connection Policy

## 4.1 Purpose

This policy defines the requirements for using the company's Virtual Private Network (VPN) to securely access company resources from outside the corporate network.

## 4.2 Scope

This policy applies to employees, contractors, and authorized users who access company systems remotely.

## 4.3 VPN Requirement

Employees must use the company-approved VPN when accessing protected internal resources from an external network.

Examples include:

- Internal applications
- File servers
- Company databases
- Internal dashboards
- Administrative systems

## 4.4 Approved VPN Software

Only VPN software provided or approved by the IT Department may be used.

Employees must not install or use unauthorized VPN applications to access company resources.

## 4.5 VPN Connection Procedure

1. Connect the computer to a trusted internet connection.
2. Open the company-approved VPN application.
3. Enter the company username.
4. Complete multi-factor authentication when requested.
5. Select the appropriate company VPN profile.
6. Click **Connect**.
7. Verify that the VPN status shows **Connected**.
8. Access the required company resources.

## 4.6 Public Wi-Fi

Employees should avoid accessing sensitive company information over unsecured public Wi-Fi.

When public Wi-Fi must be used, the company-approved VPN must be connected before accessing protected company resources.
